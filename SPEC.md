# Docent — engineering spec (v0.1 · 2026-09-26)

Docent turns a lesson into a page that reads like a textbook when you scroll it and plays like a lecture when you press Play. While playing, a Korean narrator reads the lesson, the page scrolls itself so the spoken sentence stays on the **reading line**, the spoken words fill in as they are said, and tagged effects fire once at their spot. It is plain HTML/CSS/JS on static hosting (GitHub Pages). No framework, no bundler.

This file is the contract between everyone building Docent. If something here blocks you, message the root agent instead of silently diverging.

## 1. Principles (apply to every decision)

1. **Reading first.** Most of a lesson is text, code, tables and pictures. Everything must be readable with JavaScript off (the compiler emits final-state HTML).
2. **Few, strong moments.** Flashy components appear only at fixed spots. A course uses at most 10 component types (listed in §5).
3. **Effects are seen.** An effect never fires while the page is moving. If the camera (auto-scroll) or the reader is scrolling, the effect waits until the page settles, then plays once. While an effect plays in Play mode the camera holds still.
4. **The reader wins.** Any manual scroll/wheel/touch/keyboard navigation during playback detaches the camera (audio keeps playing). A pill "지금 읽는 곳으로" re-attaches it.
5. **One focal motion at a time.** Never animate two things that compete for attention.
6. **Respect prefers-reduced-motion.** Camera jumps instead of gliding, effects become instant state changes, intros become a static title card.
7. **No AI-slop visuals.** No indigo/violet gradients, glassmorphism, glowing dots, emoji icons, pastel icon tiles, gradient-clipped headlines, or "01/02/03" kicker spam. Use the tokens in `styles/tokens.css` only.

## 3. Lesson script format (content/lessons/<id>.md)

Front matter, then chapters. Everything that is not inside a block tag is narrated body text.

```
---
id: variables
number: 1
title: 변수
subtitle: 값에 이름표 붙이기
motif: tag            # intro symbol: tag | branch | loop | list | generic
next: conditionals    # optional
---

[intro] 파이썬 첫걸음, 첫 번째 레슨. 변수.        ← intro voice-over (one line)

# 값을 기억해야 할 때                              ← chapter opener; narrator reads the title

본문 문장입니다. 문장마다 하나의 낭독 구간이 됩니다.
변수는 값에 붙인 [pop]이름표[/pop]예요.            ← word pop on 이름표
`price = 4500`{프라이스 이콜 사천오백}처럼 써요.   ← inline code with its spoken form
{4,500원|사천오백 원}                             ← any shown|spoken substitution

[code c2]
price = 4500
print(price * 3)
[/code]

[run c2] 실행하면 13500이 나와요.                  ← run all lines of c2 when narration reaches here
[run c2:2] 두 번째 줄이 결과를 출력해요.            ← highlight line 2 and reveal its output
[burst] 이름은 그대로인데 값이 바뀌었어요!           ← one-time burst at this spot

[figure f1 name-tag]
이름표 price가 4500이 든 상자에 붙어요.            ← caption (not narrated)
[/figure]
[step f1 1] 이름표가 상자에 붙는 모습을 보세요.      ← advance figure f1 to step 1

[tip]
본문 흐름 밖의 짧은 참고. 낭독하지 않습니다.
[/tip]

[turn t1 front="변수" back="값에 붙인 이름"]
[flip t1] 한 줄로 말하면, 변수는 값에 붙인 이름이에요.

[checkpoint] 여기까지 잘 따라왔어요.               ← mid-lesson break (exactly once)

[outro]
- 변수는 값에 붙인 이름표다
- = 는 오른쪽 값에 왼쪽 이름을 붙인다
- 이름표는 다른 값으로 옮겨 붙일 수 있다
[/outro]
[outro-say] 오늘은 변수를 배웠어요. 다음 시간에는 조건문으로 갈림길을 만들어 봐요.

[practice]
```

Rules the compiler enforces: sentence = segment (split on . ? ! followed by space/end, never inside code or {…}); inline tags attach a cue to the first spoken word that follows the tag (or to the wrapped words for [pop]); [checkpoint] exactly once near the middle; [turn] at most once; [burst] at most once per chapter; every [code] block must run in Python 3 and its output is captured at build time (never hand-written).

## 4. Compiled lesson (data/lessons/<id>.json)

```json
{
  "id": "variables", "number": 1, "title": "변수", "subtitle": "값에 이름표 붙이기", "motif": "tag",
  "course": { "id": "python-first-steps", "title": "파이썬 첫걸음" },
  "next": { "id": "conditionals", "title": "조건문" },
  "chapters": [ { "id": "ch1", "title": "값을 기억해야 할 때", "block": "ch1" } ],
  "segments": [
    {
      "id": "s12", "block": "p7", "chapter": "ch2",
      "text": "변수는 값에 붙인 이름표예요.",          // what the page shows
      "say":  "변수는 값에 붙인 이름표예요.",          // what the narrator says (Hangul-normalised)
      "units": [ { "text": "변수는", "say": [0, 1] }, { "text": "값에", "say": [1, 2] } ],   // display unit -> spoken-word range [from, to)
      "cues": [ { "unit": 3, "fx": "pop", "target": "s12-u3" } ],
      "pauseBefore": 0, "pauseAfter": 250            // ms of silence the voice pipeline inserts
    }
  ]
}
```

Spoken words are `say.split(/\s+/)`. `units[i].say` is a half-open index range into that list.

## 5. Components (the whole kit — 10 types)

| fx | block/element | purpose | budget |
|---|---|---|---|
| intro | section.blk.intro | full-screen title sequence; only course/number/title/subtitle/motif change | 1 per lesson |
| chapter | section.blk.chapter | dark title band opening a chapter | 1 per chapter |
| pop | span.fx-pop | the spoken word itself animates | ≤ 1 per paragraph |
| burst | any anchor | one-time sparks/confetti from the anchor | ≤ 1 per chapter |
| flip | div.blk.turn | definition card turns once in 3D | ≤ 1 per lesson |
| run | figure.blk.code | lines light up as narrated, output appears | every code block |
| step | figure.blk.figure | diagram/comic advances one step | as needed |
| (tip) | aside.blk.tip | margin note, no animation | as needed |
| checkpoint | section.blk.checkpoint | "여기까지 왔어요" break with progress ring | exactly 1 |
| outro | section.blk.outro | recap + next lesson, leads into practice | 1 per lesson |

## 6. Effect API (src/components/index.js)

```js
export const fx = { intro, chapter, pop, burst, flip, run, step, checkpoint, outro };
// every fx: (el, opts) => Handle
// Handle = { duration: number /* ms, known synchronously */, done: Promise<void>, finish(): void /* jump to end state */ }
// opts = { mode: 'play'|'read', intensity: 'soft'|'normal'|'strong', reduced: boolean, sound: boolean,
//          style?: 'cinema'|'editorial'|'playful' /* intro only */, line?: number /* run */, n?: number /* step */ }
export function prime(root)   // put every effectable element under root into its initial (pre-effect) state
export function settle(el)    // final state instantly (seek forward past it)
export function reset(el)     // initial state instantly (seek backward before it)
```

Duration budgets at intensity 'normal' (the compiler inserts this much silence so the camera can hold still): intro 4800, chapter 1400, pop 700, burst 1100, flip 1000, run 380 per line + 420 for output, step 900, checkpoint 1600, outro 1800. 'soft' ≤ 0.7×, 'strong' ≤ 1.3×. Sounds (WebAudio, synthesized, no files) only for intro, chapter, checkpoint, outro and only when opts.sound is true.

Initial vs final state: without JS the page shows the final state. `prime()` hides what effects will reveal (e.g. code output, figure steps, the back of a turn card) but never hides body text.

## 8. Voice pipeline and timings

CLI: `node scripts/voice/build.mjs <lessonId> [--provider <name>]` reads data/lessons/<id>.json, synthesizes each segment's `say` separately (cache by hash of provider+voice+say in .cache/voice/), inserts `pauseBefore`/`pauseAfter` silence, concatenates, encodes `audio/<id>.m4a` (AAC, mono), and writes:

```json
{ "version": 1, "lesson": "variables",
  "voice": { "provider": "supertonic", "model": "supertonic-2", "speaker": "F1", "license": "…" },
  "audio": "audio/variables.m4a", "duration": 241.37,
  "segments": [ { "id": "s12", "start": 51.20, "end": 54.85, "words": [[51.20, 51.61], [51.66, 52.10]], "align": "forced", "confidence": 0.82 } ] }
```

`words.length` must equal the number of spoken words of that segment. Times are absolute seconds in the combined audio. Word times come from forced alignment of the known text (wav2vec2 Korean, cached at ~/.cache/huggingface/hub/models--kresnik--wav2vec2-large-xlsr-korean); fall back to character-proportional timing per segment and mark `"align": "proportional"`. Providers are pluggable; the page never depends on which one made the audio.

## 9. AI practice (src/practice/)

`mountPractice(sectionEl, { lessonId, dataUrl, ai })` renders the practice section at the end of a lesson. Data (content/practice/<id>.json): themes the learner picks from (e.g. 카페, 게임, 음악, 여행), each with exercises {id, level, title, prompt, starter, checks[], hints[3], solution}. Checks are stdout comparisons or Python assert snippets run after the learner's code in the same namespace. Code runs in the browser with Pyodide (lazy-loaded only when the learner presses 실행). Every exercise's solution must pass its checks and its starter must fail them — verified by a script with real Python before commit. AI feedback: if a local Ollama server answers at http://127.0.0.1:11434, stream short Korean feedback on the learner's code; otherwise fall back to the hint ladder. Never ship API keys.

## 10. Engine behaviour (reference)

States: read (no audio), playing, paused. The rAF loop reads audio.currentTime, finds the active segment and word, fills spoken words (ink) and leaves the rest of the sentence dim, marks the active sentence with a soft band. The camera starts moving ~450 ms before a segment whose element is outside the reading band (26%–62% of the viewport) and eases it to the reading line (38%). Cues fire at their word's start time; if the camera is moving, the cue waits until it settles. While an effect runs, the camera does not move. Seeking calls settle()/reset() on everything between the old and new time. In read mode, effectable elements fire once when they are in the reading band and the page has been still for 180 ms. Dock: play/pause, chapter title, progress with chapter ticks, time, speed (1×/1.25×/1.5×). Keyboard: Space, ←/→ (previous/next sentence).
